# Stampify

**Turn study into stamps.** Stampify is a free language-learning web app that you can install on your phone. Each language has its own passport, and every study session earns a stamp.

**Try it:** https://stampify.entu.workers.dev

## Languages

Mandarin Chinese, German, Spanish, French, Italian, Portuguese (Brazilian), Dutch, Polish, Russian, Japanese, Korean and Hungarian. The app's interface is in English.

Levels run from 1 to 6: HSK for Chinese, TOPIK for Korean and CEFR A1–C2 for the other languages.

## What's inside

- **Practice:** minigames for vocabulary, sentences, grammar, verb conjugation, noun genders, listening and writing scripts (kana, hangul, Cyrillic and Chinese characters). All of them feed one daily XP goal and streak.
- **Review:** spaced-repetition flashcards for words and sentences.
- **Read:** graded texts that range from short articles to book-length stories. Tap any word to look it up or save it.
- **Resources:** guidebooks and cheat sheets for German, Chinese and Korean.
- **Tools:**
  - *Watch:* study a YouTube video or a local video using its subtitles.
  - *Analyse:* paste text, load a subtitle file or a screenshot, or read live captions from your screen; matching words can be saved.
- **Optional account:** sign in with only a username and password to sync progress between devices. Without an account, everything stays on your device, and you can export a backup file.

> The learning materials are generated by an LLM and may contain mistakes. Use Stampify alongside other learning resources.

## Running it locally

You need [Node.js](https://nodejs.org) 22 or newer.

```bash
npm install
npm run dev        # the app at http://localhost:5173
npm run dev:api    # optional: the accounts/sync API on a local database
```

Other commands:

| Command | What it does |
| --- | --- |
| `npm run build` | Builds the content library, type-checks, and builds the app into `dist/` |
| `npm run validate` | Checks all learning content for errors |
| `npm run test:subs` | Runs the caption-reading tests on sample screenshots |
| `npm run test:hu` | Runs the Hungarian word-form tests |
| `npm run deploy` | Builds and deploys to Cloudflare (needs `npx wrangler login`) |

## How it's built

- **App:** [Preact](https://preactjs.com) + TypeScript, built with [Vite](https://vite.dev) as an installable PWA that works offline.
- **Content:** TypeScript data files in `src/content/<language>/`. See `docs/content-guide.md` for the writing rules.
- **Server:** a small [Cloudflare Worker](https://developers.cloudflare.com/workers/) (`worker/index.ts`) with a D1 database. It handles only accounts and sync; everything else is static files.
- **Speech:** the browser's built-in text-to-speech. **OCR:** [Tesseract.js](https://github.com/naptha/tesseract.js). **Stroke order:** [Hanzi Writer](https://hanziwriter.org).
